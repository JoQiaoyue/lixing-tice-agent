# 砺行体测小管家

面向大学生体质健康测试与体育课期末考核的智能备考助手。输入当前成绩与目标分，即可获得分数预测、弱项诊断、定制训练计划、动作纠错与考前指导，并记录每次成绩追踪提升曲线。

> 参赛作品：第四届 AIGC 大赛　|　形态：单文件 Web 应用（零依赖，双击即用）

## 快速开始

直接双击 `index.html`（或用浏览器打开），无需安装、无需联网、无需服务器。

数据保存在本机浏览器中，登录后按账号隔离保存。

## 功能

| 模块 | 说明 |
|---|---|
| 成绩测评 | 按《国家学生体质健康标准（2014年修订）》与校内课程考核标准双标准折算，输出预测总分、单项得分、弱项诊断（含"再提升 X 可 +Y 分"性价比） |
| 训练计划 | 距考试 >2 周输出周计划、≤2 周自动切换逐日冲刺计划；均按练习性价比排序 |
| 动作教室 | 8 个项目的动作要点、常见错误与纠正方法，附抖音/小红书/B站教学视频入口，支持上传自己的动作视频/照片做动作分析 |
| 考前须知 | 证件提醒、热身动作、用餐注意、各项目文字小妙招与视频入口、考试规则 |
| 成绩档案 | 分项目记录成绩，可逐项查看提升曲线（时间类项目标注"越低越好"），自动计算总分 |
| 账号系统 | 手机号 + 用户名 + 密码登录，个人档案与成绩按账号记忆、互相隔离 |

## 支持的身份差异

- **年级/课程**：2026级体能课、2025级专项课、2024级竞赛课、2026级中外合作办学（各自项目构成不同）
- **班型**：标准班、体质健康提升训练班（BMI≥30，减重模式计划）、体育保健班（出勤 0–65 分，轻运动计划）
- **性别**：项目与标准自动切换（1000米/引体向上 ↔ 800米/仰卧起坐）

## 数据说明

- 国家标准评分表取自《国家学生体质健康标准（2014年修订）》官方发布版本。
- 校内课程考核标准中，**男生立定跳远/50米/折返跑**与**女生2000米**为按国家标准差值推算的估算值，应用内已标注"以体育部公布为准"。
